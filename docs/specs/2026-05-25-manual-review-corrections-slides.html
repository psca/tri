Local Race Authority

Manual Review & Corrections

Small race-day adjudication layer. Fast enough for a helper. Auditable enough to trust after BLE gets noisy.

Problem

BLE helps. Humans still decide edge cases.

Missed passBeacon hidden, packet loss, weak RSSI, or athlete crosses too fast.
Bad passDuplicate, lingering near gate, wrong direction, or false positive.
Wrong timeSystem saw athlete, but best timestamp needs operator adjustment.
Status callDNF, DQ, manual finish, or restart racing status.

Principle

Never edit history. Append correction facts.

BLE/raw detections captured
Race engine accepts route events
Operator adds correction facts
Review/export projection shows corrected truth

Correction Types

Four actions only.

manual_add_passAdd missing route event at known wall-clock time.
manual_reject_passReject an accepted event without deleting it.
manual_override_timeChange displayed time while preserving original.
mark_statusSet DNF, DQ, manual finished, or racing.

Data Model

One append-only table.

manual_corrections
- local_sequence_number
- race_id
- correction_type
- athlete_id
- route_event_id
- target_local_sequence_number
- corrected_time_wall
- status
- reason
- created_at
- created_by

Projection

Corrected state is derived, not hand-mutated.

1. Route configExpected ordered events and athletes.
2. Accepted eventsBLE-derived pass facts from race engine.
3. CorrectionsManual add, reject, override, status facts.

Invalid stale corrections become warnings, not crashes.

API

Three local endpoints.

GET  /api/review/state
GET  /api/corrections
POST /api/corrections
Allowed liveCorrections can happen during race or after close.
ValidatedUnknown athlete/event or missing reason returns 400.

Safety UX

No accidental one-click edits.

Every correction opens a plain-language confirmation.

Add manual pass for Bob at Run 1 Lap 2, time 09:21:00?
Reason: Saw athlete cross while BLE missed.

Cloud Sync

Cloud sees corrected local truth.

  • Corrections enqueue through existing SQLite outbox.
  • race_state_snapshot includes correction effects.
  • manual_correction payload syncs audit visibility.
  • Cloud remains read-only. No remote correction commands.
